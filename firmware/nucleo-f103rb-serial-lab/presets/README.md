# NUCLEO-F103RB Modbus 명령 모음

SERIAL-LAB 1.7.1의 Unit 1, 115200 / 8N1 / 흐름 제어 없음에서 사용하는 명령 정의다.
[주소표](../MODBUS-MONITOR.md)의 쓰기 가능한 LED와 RAM만 사용한다.
`modbus-commands.json`은 앱 프로필의 `ModbusCommands`에 병합하는 정의 묶음이다.
등록하거나 프로필을 불러오는 것만으로는 송신하지 않는다.

## 들어 있는 명령

| 명령 | 쓰기 대상 (0 기준) | 값·확인 |
| --- | --- | --- |
| LED 켜기 | Coil 4096 / 0x1000 | 1을 쓰고 FC04 주소 4103의 bit 0 = 1 확인 |
| LED 끄기 | Coil 4096 / 0x1000 | 0을 쓰고 FC02 주소 4097의 bit 0 = 0 확인 |
| LED 켜기 → 끄기 | 위 두 단계 | 앞 단계 확인 후 다음 단계 실행 |
| RAM UInt16 | Holding 4112 / 0x1010 | 123, 쓴 값 재조회 |
| RAM Int16 | Holding 4113 / 0x1011 | -123, 쓴 값 재조회 |
| RAM 배율값 | Holding 4114 / 0x1012 | Int16 × 0.1에 25.3 입력 → 원시 값 253, 재조회 |
| RAM UInt32 | Holding 4116–4117 / 0x1014 | 305419896, 두 워드 함께 쓰고 재조회 |
| RAM Float32 | Holding 4118–4119 / 0x1016 | 1.5, 두 워드 함께 쓰고 재조회 |
| RAM Int32 | Holding 4120–4121 / 0x1018 | -123456789, 두 워드 함께 쓰고 재조회 |
| RAM 순차 쓰기 | Holding 4112 / 0x1010 | 6 → 7 → 15, 각 단계 재조회 |

각 명령의 이름에는 `NUCLEO`를 붙인다. 기존 형식 예제인 Holding 0x1004–0x1009를 보존하도록
별도의 RAM 주소를 사용한다. 실행하면 해당 RAM 값 또는 LED 상태가 바뀐다.
LED의 별도 상태 확인은 펌웨어가 보고하는 명령 상태이며 전기적인 광량 측정은 아니다.
켜기 → 끄기에는 대기 단계가 없어 LED가 잠깐만 켜질 수 있다. 켜짐을 직접 보려면 **LED 켜기**를 실행한다.

## 먼저 실행해 보기

1. COM3(ST-LINK VCP)의 115200 / 8N1로 연결한다. 다른 펌웨어를 올린 보드라면 먼저 해당 주소표를 확인한다.
2. **Protocol → Modbus RTU · 값 읽기/쓰기 → 명령…**을 연다.
3. **NUCLEO · LED 켜기**를 고르고 ID 1·쓰기 주소 4096·별도 상태 확인을 확인한다.
4. **선택 명령 실행**을 누른다. LD2가 켜지고 단계별 결과에 상태 확인 결과가 표시된다.
5. **LED 끄기** 또는 **LED 켜기 → 끄기**를 선택해 실행한다.
6. 진행 중인 작업을 멈추려면 팝업의 **명령·폴링 정지**나 상단 정지를 누른다.
   이미 보낸 쓰기는 취소되지 않으므로 이후 실제 값을 확인한다.

이 명령은 자체 대상 ID·주소를 갖는다. 표에서 고른 감시 그룹과 명령 실행 대상이 같을 필요는 없다.
읽기 전용 항목과 겹치는 경우 앱의 기존 보호 규칙을 따른다.
펌웨어가 LAB 텍스트 모드라면 폴링·명령 실행을 멈추고 `RTU` + CRLF로 전환한 뒤 사용한다.
모드 변경·오류 주입·전체 초기화는 이 정상 제어 목록에 넣지 않는다.

## 새 명령·단계와 저장 버튼

기존 명령은 **명령 편집…**에서 열어 구조를 볼 수 있다. 새로 작성할 때는 다음 순서를 따른다.

1. **새 명령**을 누르고 이름을 입력한다. 첫 단계에 이름·장치 ID·쓰기 영역·주소·값·확인 방식을 입력한다.
2. 두 번째 단계가 필요하면 **새 단계**를 누른다. 유효한 첫 단계는 편집기 안의 목록에 자동으로 반영된다.
3. 잘못된 입력이 있으면 해당 값을 고친다. 다른 단계로 이동해도 입력이 사라지지 않으며, 오류가 있는 현재 단계에서는 이동을 막는다.
4. 편집을 마쳤으면 **모니터에 적용**을 한 번 누른다. 현재 초안까지 실행 목록에 반영하고 명령 팝업으로 돌아온다.
   이때는 장치에 보내지 않는다. **선택 명령 실행**을 눌러야 송신한다.
5. 다음에 앱을 열 때도 유지하려면 **대상 설정 → 프로필 저장**을 누른다.
   **취소**는 이번 편집을 적용하지 않으며, 편집기 안에서 자동 반영했던 내용도 원래 실행 정의를 바꾸지 않는다.

현재 설치된 명령 모음은 프로필에 저장돼 있으므로 바로 선택·실행할 수 있다.
명령을 수정한 뒤에는 **모니터에 적용 → 프로필 저장** 순서로 반영한다.
