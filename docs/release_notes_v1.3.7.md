# Serial Monitor v1.3.7

## 시퀀스와 이벤트

- 자동 재연결이 활성화된 상태에서 연결이 끊기면 실행 중인 시퀀스의 진행 위치와 반복 횟수를 유지하고, 연결 복구 후 이어서 실행합니다.
- 연결 끊김으로 송신에 실패한 Step은 재시도합니다. 실패 직전에 장치가 명령을 받았다면 중복 수신될 수 있습니다. Stop과 수동 연결 해제는 재연결 대기도 취소합니다.
- 여러 부분 RX 조각에 나뉜 Terminal 키워드를 감지하도록 개선했습니다.
- 이벤트 룰의 배경색을 목록에서 바로 설정할 수 있도록 개선했습니다.

## 성능과 로그 저장 안정성

- HEX 포맷팅의 메모리 할당을 줄이고 UI 배치 작업량에 제한을 적용했습니다.
- 파일 쓰기와 타임아웃 감시를 배치 단위로 처리해 저장 경로의 부담을 줄였습니다.
- 디스크 부족, 저장 대기열 포화, 종료 시 미저장 데이터를 실패 상태와 카운터로 표시하도록 보완했습니다.
- 연결 종료 시 수신 데이터와 마지막 부분 행을 처리한 뒤 파일을 flush하도록 정리 순서를 개선했습니다.
- 목록 전환 효과와 도구 모음 스크롤 애니메이션을 비활성화했습니다.

## 검증과 배포

- Debug와 Release에서 각각 자동 테스트 478개(Core 35개, WinUI 443개)를 통과했습니다.
- Windows 10/11 x64용 Release 설치 EXE, 포터블 ZIP 및 각각의 SHA-256 체크섬을 제공합니다.
- Microsoft Edge WebView2 Runtime이 필요합니다.
- 실제 장비의 장기간 연속 실행과 WinUI 화면 수동 검증은 이번 릴리즈 검증에 포함되지 않았습니다.
