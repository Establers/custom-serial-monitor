# Serial Monitor v1.3.1

출시일: 2026-08-06

## 검색 안정성

- native UI에서 xterm으로 보내는 검색 요청을 한 번에 하나씩 처리하도록
  직렬화했습니다. 실행 중 새 요청이 들어오면 불필요한 중간 요청을 버리고 가장
  최신 요청만 이어서 처리합니다.
- F3와 Shift+F3를 빠르게 반복해도 검색 탐색 작업이 동시에 실행되지 않습니다.
  대기 중인 입력은 순이동 횟수와 방향으로 병합되어 활성 검색 snapshot과의
  경합을 방지합니다.
- WebView2 검색 응답에 5초 제한을 추가했습니다. xterm 검색 bridge가 멈추더라도
  후속 탐색 요청이 무기한 쌓이지 않고 Health 진단에 오류가 표시됩니다.
- 창 종료나 검색 세대 변경 시 대기 중인 검색 작업을 취소해 오래된 결과가 UI에
  적용되지 않도록 했습니다.

## 로그 툴바 정리

- Auto Scroll, Pause Rendering, Clear Screen을 로그 툴바 왼쪽의 항상 보이는 영역으로
  옮겼습니다.
- 스크롤이 필요한 검색·필터 영역의 최소 폭을 줄여 작은 창에서 주요 조작에 더
  빠르게 접근할 수 있습니다.
- 중복된 빠른 Mark 버튼을 제거했습니다. 마커 기능 자체와 기존 명령 경로는
  유지됩니다.

## 검증과 호환성

- 최신 요청만 실행하는 동작, 대기 요청 병합, 종료 취소를 검증하는 테스트 3개를
  추가했습니다.
- Release 구성에서 Core 테스트 35개와 WinUI 테스트 320개, 총 355개를 모두
  통과했습니다.
- Windows 10/11 x64용이며 xterm 로그 화면에는 Microsoft Edge WebView2 Runtime이
  필요합니다.

## 설치 안내

- 일반 설치용 Inno Setup 실행 파일과 관리자 권한이 필요 없는 포터블 ZIP을 함께
  제공합니다.
- 두 패키지 모두 SHA-256 체크섬 파일을 제공합니다.
- 설치 파일은 코드 서명이 없어 Windows SmartScreen에서 알 수 없는 게시자 경고가
  표시될 수 있습니다.
