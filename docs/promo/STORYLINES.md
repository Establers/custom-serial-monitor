# 영상 구성

사용자가 결과 파일까지 요청했으므로 1안을 선택해 제작한다.

1. **핵심만 보는 기능 투어 (선택)** — 작은 실제 화면과 큰 한글 문구로 시퀀스 → 룰 → AI 제어를 소개한다. 0초부터 TX/RX Check 화면과 “반복 검증, 더 간단하게”를 보여준다. README에서 무음 재생을 전제로 한다.
2. **하나의 오류를 따라가기** — Error 로그를 룰로 발견하고 시퀀스로 검증을 정리하는 구성. 현재 요청보다 로그 시연 비중이 커 제외했다.
3. **AI 요청에서 RX까지** — 플러그인 요청과 실제 장치 응답을 따라가는 구성. 장치 동작을 새로 수행하는 대신 세 기능을 균형 있게 소개하는 1안을 택했다.

실제 앱을 작게 보여주고 특징적인 부분만 쓰라는 사용자 지시에 맞춰, 전체 창 대신 설정창의 관련 영역만 발췌했다.
