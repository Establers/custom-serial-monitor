# 검토용 스토리보드

사용자 방향: 실제 앱 화면을 작게 배치하고 특징적인 부분만 보여주는 20초 한글 홍보영상. 최신 v1.6.4 포터블을 캡처했다. 무음 README GIF와 동일한 구성의 MP4를 만든다.

| 구간 | 한글 문구 | 실제 화면 |
| --- | --- | --- |
| 0–3초 | 반복 검증, 더 간단하게 | TX / RX Check 목록 |
| 3–8초 | 순서대로 보내고 응답까지 확인 | 반복 3회·4개 단계·기대 패턴과 확인 시간 |
| 8–13초 | 놓치기 쉬운 로그, 룰로 찾아내세요 | Error 룰의 이벤트·강조·필터와 알림·시퀀스 트리거 |
| 13–17.6초 | AI에게 요청하고 실제 RX로 확인 | Codex 설치 안내 + 명령 전송·RX 수집·응답 해석 설명 |
| 17.6–20초 | Serial Monitor / 다음 디버깅부터 함께하세요 | 실제 앱 아이콘·저장소 주소 |

가짜 앱 화면이나 시리얼 응답 성공 결과는 사용하지 않는다. 시퀀스는 설정 예시이며 장치에 명령을 전송하지 않았다. 전체 화면의 작은 글씨 대신 큰 한글 문구가 내용을 전달해야 한다.
