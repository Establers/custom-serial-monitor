# 검토용 스토리보드

사용자 방향: 실제 앱 화면을 작게 배치한 20초 한글 홍보영상에 제공받은 음성 5개를 넣는다. 최신 v1.6.4 포터블 화면을 사용하고, 각 대사의 시작에 맞춰 장면 길이를 조정한다. GIF는 같은 영상의 무음 미리보기다.

| 구간 | 한글 문구 | 실제 화면 |
| --- | --- | --- |
| 0–2.333초 | 반복 검증, 더 간단하게 | TX / RX Check 목록 |
| 2.333–7.433초 | 순서대로 보내고 응답까지 확인 | 반복 3회·4개 단계·기대 패턴과 확인 시간 |
| 7.433–12.267초 | 놓치기 쉬운 로그, 룰로 찾아내세요 | Error 룰의 이벤트·강조·필터와 알림·시퀀스 트리거 |
| 12.267–16.267초 | AI에게 요청하고 실제 RX로 확인 | Codex 설치 안내 + 명령 전송·RX 수집·응답 해석 설명 |
| 16.267–20초 | Serial Monitor / 다음 디버깅부터 함께하세요 | 실제 앱 아이콘·저장소 주소 |

내레이션 대본과 각 구간의 프레임 수는 [voiceover.json](voiceover.json)에 기록한다. 원본은 사용자 제공 파일이며 별도 TTS 생성은 수행하지 않는다.

가짜 앱 화면이나 시리얼 응답 성공 결과는 사용하지 않는다. 시퀀스는 설정 예시이며 장치에 명령을 전송하지 않았다. 전체 화면의 작은 글씨 대신 큰 한글 문구가 내용을 전달해야 한다.
