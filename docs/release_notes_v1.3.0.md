# Serial Monitor v1.3.0

출시일: 2026-08-03

## 검색 기능 개선

- 현재 보이는 로그 검색에 `Aa`(대/소문자 구분), `|ab|`(단어 단위),
  `.*`(정규식) 옵션을 추가했습니다.
- 검색창에서 `Alt+C`, `Alt+W`, `Alt+R`로 각 옵션을 빠르게 전환할 수 있습니다.
- 검색어 또는 옵션을 수정하는 동안 기존 결과를 `Stale` 상태로 유지하고,
  `Enter` 또는 `Refresh`를 실행할 때만 새 결과로 교체합니다.
- 잘못된 정규식은 읽을 수 있는 오류로 표시하며, 선택하거나 강조할 범위가 없는
  zero-length 정규식 결과는 안전하게 제외합니다.
- 반복 일치는 한 로그 행으로 묶어 표시하면서 F3/Shift+F3 탐색과 xterm 선택
  범위는 개별 일치 위치를 정확하게 유지합니다.

## 다중 로그 필터

- 현재 표시 모드에서 사용할 로그 필터를 여러 개 동시에 선택할 수 있습니다.
- 선택한 규칙 중 하나라도 일치하면 로그를 표시합니다.
- Flyout에서 선택을 변경한 뒤 `Apply`를 눌러야 활성 필터가 바뀌므로, 설정 도중
  화면이 예기치 않게 변하지 않습니다.
- `ALL`은 개별 선택을 해제하고 전체 로그 표시로 안전하게 복귀합니다.

## 진단 UI 경량화

- 전체 진단 문자열과 많은 속성을 주기적으로 다시 만들던 Diagnostics 탭을
  제거했습니다.
- 하단 Footer에는 연결, 디스크, 메모리, 큐, drop, 드라이버 오류, 이벤트,
  파일 기록 상태 등 운영에 필요한 핵심 상태만 유지합니다.
- Health에 경고 또는 오류가 있으면 원인 툴팁에 최대 5개를 표시하고 나머지는
  추가 건수로 요약합니다.
- Footer를 우클릭해 상태를 복사하면 정상 상태에서도 현재 Footer 한 줄을
  복사하며, Health 원인이 있으면 전체 원인을 함께 복사합니다.
- 백그라운드 서비스와 각 observer의 오류 키를 분리했습니다. 종료된 observer의
  오류가 다른 서비스의 정상 상태에 의해 지워지지 않으며, 해당 작업이 실제로
  복구되거나 재시작된 경우에만 해제됩니다.
- 마지막 런타임 오류 파일은 `%LOCALAPPDATA%\SerialMonitor\diagnostics`에 계속
  보존됩니다.

## 안정성과 호환성

- 진단 UI 제거는 serial RX, parsing, 비동기 파일 기록, 이벤트 탐지, Bridge의
  기존 bounded queue/channel 구조를 변경하지 않습니다.
- UI 표시 로그는 계속 최대 200,000줄로 제한되며 전체 로그는 비동기로 파일에
  기록합니다.
- Release 전체 빌드는 경고 0개, 오류 0개이며 Core 테스트 35개와 WinUI 테스트
  317개, 총 352개를 통과했습니다.
- Windows 10/11 x64용이며 xterm 로그 화면에는 Microsoft Edge WebView2 Runtime이
  필요합니다.

## 설치 안내

- 일반 설치용 Inno Setup 실행 파일과 관리자 권한이 필요 없는 포터블 ZIP을 함께
  제공합니다.
- 두 패키지 모두 SHA-256 체크섬 파일을 제공합니다.
- 설치 파일은 코드 서명이 없어 Windows SmartScreen에서 알 수 없는 게시자 경고가
  표시될 수 있습니다.
