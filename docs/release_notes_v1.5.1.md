# Serial Monitor v1.5.1

2026-10-26

## CLI / MCP 시퀀스 자동화

- CLI/MCP에서 명령 시퀀스를 등록·조회·삭제하고 GUI 목록 및 프로필과 공유할 수 있습니다. 같은 이름을 교체할 때는 명시적인 덮어쓰기 옵션이 필요합니다.
- `serialctl sequence run`으로 백그라운드 실행을 시작하고 실행 ID로 상태 조회·취소를 요청합니다. 접수된 시퀀스는 CLI/MCP 연결이 끝나도 GUI에서 계속 실행됩니다.
- 단계별 Terminal/HEX 전송 형식, 줄 끝, RX 수집 시간, 지연과 선택적인 기대 응답을 저장합니다. 전체 실행의 원본 RX를 하나의 캡처에 보존하고 단계별 바이트 구간을 조회할 수 있습니다.
- 기대 응답은 연속된 텍스트/HEX 바이트의 정확 일치로 확인합니다. 수신 chunk 경계를 가로지르는 응답도 확인하며, printf가 섞여 불일치한 결과만으로 제품 실패를 단정하거나 명령을 자동 재전송하지 않습니다.
- 첫 TX 전에 전체 정의와 연결을 검증하고 실행 시간·단계 수·캡처 크기·보관 이력을 제한합니다. GUI 전송·Bridge·재연결 등과의 제어 충돌을 방지합니다.

## 연결 설정 및 수신 안정성

- `serialctl configure`와 MCP `serial_configure`에서 연결을 유지한 채 baud rate와 HEX byte timeout을 변경할 수 있습니다. 드라이버가 지원하는 사용자 지정 baud rate도 허용하며 적용된 값을 확인합니다.
- `serialctl mode --set terminal|hex`와 MCP `serial_set_mode`로 GUI의 RX/TX 모드를 바꿀 수 있습니다. 모드 변경 시 화면 로그와 검색 결과를 초기화하며 저장 로그와 원본 캡처는 유지합니다.
- Terminal 수신에서 여러 조각으로 나뉜 UTF-8·CP949 문자를 유지해 부분 화면 갱신 시 한글이 깨지는 문제를 수정했습니다. 모드 전환·연결 종료 시 미완성 문자 처리와 다음 세션의 분리를 보완했습니다.
- 연결 중 HEX timeout 변경을 수신 묶음에 반영하면서 원본 바이트와 RX 캡처를 유지합니다.

## 프로필·설치·화면 개선

- 여러 창이 같은 프로필을 저장할 때 다른 창의 시퀀스 추가·수정·삭제를 보존합니다. 같은 시퀀스를 서로 다르게 수정하면 충돌을 표시하고 덮어쓰기를 거절합니다.
- 프로그램 설치 위치 선택을 활성화하고 한국어 설치 안내를 추가했습니다. 스킬은 `SerialMonitorSkills.zip`으로 별도 설치하며 프로그램 설치·업데이트 시 기존 스킬을 변경하지 않습니다.
- 스킬 설치에서 AI 도구별 사용자 지정 경로와 한글·공백·특수문자 경로를 지원하고, 여러 도구 설치 시 사전 검사와 실패 복구를 보완했습니다.
- Terminal/HEX 선택을 연결 도구 모음의 PORT 왼쪽으로 옮기고 모드별 설명을 추가했습니다. 다른 제어 작업이 진행 중일 때 모드 변경을 잠급니다.
- 배경 불투명도 입력을 0~100 정수로 제한하고 범위를 초과한 값·잘못된 입력 처리를 보완했습니다.

## 배포

- `SerialMonitorSetup.exe`: Windows 10/11 x64용 일반 설치 파일
- `SerialMonitorPortable.zip`: 프로그램 포터블 배포
- `SerialMonitorSkills.zip`: 스킬 전용 설치 패키지
- 각 파일의 `.sha256` 체크섬을 제공합니다. 로그 화면에는 Microsoft Edge WebView2 Runtime이 필요합니다.

## 검증

- Debug·Release 전체 솔루션 빌드가 각각 경고·오류 없이 완료되었습니다.
- 각 구성에서 자동 테스트 892개(Core 172개·WinUI 720개)가 통과했습니다. 명시적인 가상 COM 환경이 필요한 드라이버 테스트 1개는 건너뛰었습니다.
- 스킬 설치·패키지 테스트 11개와 사용자 지정 경로 테스트 9개가 통과했습니다.
- 실제 COM 장치 및 장시간 하드웨어 동작은 이번 자동 검증에 포함하지 않았습니다.
