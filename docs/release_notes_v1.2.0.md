# Serial Monitor v1.2.0

출시일: 2026-07-26

## 테마 및 가독성 개선

- Windows 앱 테마에 맞춰 로그 터미널, 이벤트 컨텍스트, 주요 UI 색상이
  라이트/다크 모드에 자연스럽게 적응합니다.
- Windows 고대비 테마에서도 로그와 배경의 대비를 유지하도록 개선했습니다.
- 사용자 지정 로그 배경색을 사용할 때 전경색을 자동 조정해 가독성을
  높였습니다.

## 인스펙터 사용성 개선

- 우측 인스펙터의 너비를 드래그로 조절할 수 있으며 창 크기에 맞춰 안전한
  범위 안에서 유지됩니다.
- 인스펙터를 탭 구조로 정리해 필요한 도구와 정보를 빠르게 전환할 수
  있습니다.
- 창 크기가 작을 때도 주요 컨트롤이 겹치거나 잘리지 않도록 레이아웃을
  다듬었습니다.

## HEX 및 정보 화면 개선

- HEX 선택 영역에 선택한 바이트 길이를 표시해 패킷 확인이 쉬워졌습니다.
- About 화면의 정보 구조와 표현을 정리했습니다.

## 검증

- Debug와 Release 구성에서 WinUI 테스트 177개와 Core 테스트 35개를 각각
  통과했습니다.
- 포터블 ZIP과 Inno Setup 설치 파일을 Release 구성으로 생성했습니다.

## 설치 안내

- 설치 파일은 코드 서명이 없어 Windows SmartScreen에서 알 수 없는 게시자
  경고가 표시될 수 있습니다.
