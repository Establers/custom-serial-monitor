# Serial Monitor v1.5.2

2026-10-28

## 로그 내보내기

- 상단 실시간 로깅 버튼 오른쪽, Log 탭 또는 로깅 버튼의 우클릭 메뉴에서 현재 보관 중인 로그를 별도 파일로 내보낼 수 있습니다. 필터로 숨긴 기록과 RX/TX·마커를 포함하며, 보관 한도나 Clear로 제거된 기록은 포함하지 않습니다.
- 내보내기 버튼을 누른 시점에 저장 범위를 고정합니다. 저장창을 열어 둔 동안 새로 수신한 기록은 포함하지 않으며, 기본 파일명에 첫 보관 기록 시각과 버튼을 누른 시각을 밀리초 단위로 표시합니다.
- 파일 저장은 백그라운드에서 진행하며 수신·화면 표시·실시간 파일 기록을 계속 사용할 수 있습니다. 진행률과 취소를 지원하고, 취소·실패 시 기존 파일을 미완성 내용으로 교체하지 않습니다.
- 내보내기는 한 번에 한 건만 실행하며 현재 실시간 기록에 사용 중인 파일에는 덮어쓰지 않습니다.

## 수신·Bridge 로그 안정성

- Bridge HEX 화면은 기존처럼 최대 64바이트 미리보기를 표시하고, 실시간 파일과 내보내기에는 전체 HEX 바이트를 기록합니다.
- Bridge Terminal의 idle·64KiB 묶음 경계에 걸친 UTF-8·CP949 문자를 유지하고, 모드·인코딩 전환 시 이전 스트림을 마무리합니다.
- Bridge 중지 시 접수된 로그와 마지막 묶음을 처리하고 파일·이벤트 전달을 확인합니다. 일반 시리얼 연결 종료에서도 이미 접수된 RX가 파이프라인에 남아 처리되도록 보완했습니다.
- 전체 HEX 원문을 포함한 파일 대기열 메모리를 계산하며, 수신 경로에서 UI 또는 파일 I/O를 기다리지 않는 구조를 유지합니다.

## 명령 화면 개선

- TX 입력과 Quick 명령을 로그 영역 아래에 배치하고 Quick 명령 버튼의 우클릭 메뉴에서 개별 편집·삭제를 제공합니다.
- 시퀀스 단계 더블 클릭 편집을 추가하고 단계 이름·설명의 용도와 툴팁을 보완했습니다. 이름과 설명은 장치로 전송하지 않습니다.
- 화면 지우기 아이콘과 한국어·영어 안내 문구를 개선했습니다.

## 배포

- `SerialMonitorSetup.exe`: Windows 10/11 x64용 일반 설치 파일
- `SerialMonitorPortable.zip`: 프로그램 포터블 배포
- `SerialMonitorSkills.zip`: 스킬 전용 설치 패키지
- 각 파일의 `.sha256` 체크섬을 제공합니다. 로그 화면에는 Microsoft Edge WebView2 Runtime이 필요합니다.

## 검증

- Debug·Release 전체 솔루션에서 각 구성의 자동 테스트 931개(Core 172개·WinUI 759개)가 통과했습니다. 명시적인 가상 COM 드라이버 환경이 필요한 1개는 건너뛰었습니다.
- 내보내기 취소·덮어쓰기·실시간 저장 병행, 긴 Unicode 기록, Bridge HEX 원문·문자 경계·중지 시 마지막 로그 처리를 회귀 테스트로 확인했습니다.
- 별도 활성화한 100만 건 내보내기 시험에서 전체 실시간 기록 40,000건의 개수·순서를 유지했으며 드롭·파일 오류는 0이었습니다. 로컬 디스크에서 내보내기는 약 290~337ms였고 실제 UART·느린 외장 저장장치 시험은 포함하지 않습니다.
- 스킬 설치·패키지·사용자 지정 경로 테스트 20개와 터미널 버퍼·큐 테스트 15개가 통과했습니다.
- 실제 UART 장치 및 장시간 하드웨어 동작은 이번 릴리즈 검증에 포함하지 않았습니다.
