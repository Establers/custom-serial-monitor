# v1.6.3 변경 사항

2026-10-31 교체 배포본입니다. 시퀀스 결과의 줄 단위 표시와 RX 페이지 경계 처리를 수정하고, 결과 폴더 열기·시간 선택기·로그 필터를 보완했습니다. 앞선 시퀀스 결과 축약 저장과 CLI/MCP 호환 개선도 포함합니다. 기존 v1.6.3 사용자는 새 설치 프로그램 또는 포터블을 다시 받아 적용해야 합니다.

## 빠른 명령 단축키

- 단축키 입력란을 클릭한 뒤 원하는 키를 누르는 기록 방식으로 바꿨습니다. Esc로 기록을 취소하거나 Clear로 할당을 지울 수 있습니다.
- F1 같은 사용 중이지 않은 단일 키를 지원합니다. 기능키는 명령·검색 입력 중에도 실행할 수 있으며, 문자·숫자 단일 키는 로그 영역에서 사용합니다.
- Enter, Tab, Ctrl+F/G, F3, Shift+F3, Alt+C/W/R 등 기존 기능의 키와 다른 빠른 명령의 키는 중복 등록을 막습니다. 이전 프로필의 충돌·중복 할당도 실행하지 않습니다.
- 네이티브와 브라우저가 공통 단축키 정의를 사용합니다. 새 앱 단축키도 사용자 할당에서 자동으로 보호하며, 정의를 우회하는 키 처리는 빌드 검사에서 확인합니다.
- 키를 누르고 있을 때 로그 영역의 빠른 명령이 반복 전송되지 않도록 했습니다. 비영문 배열의 단일 숫자 키를 보정하고, 조합키·IME·NumLock 동작은 유지합니다.

## 시퀀스 실행 결과

- Terminal RX를 내부 수신 조각마다 나누지 않고 줄바꿈 기준으로 합쳐 표시합니다. 시간 형식과 TX/RX 접두사는 메인 로그 설정을 따르고, 여러 조각에 걸친 일치 범위 강조도 유지합니다.
- 16KiB RX 페이지 사이에 CRLF 상태를 전달합니다. 이전·다음 페이지 이동에서 불필요한 빈 줄이나 줄바꿈이 생기는 문제를 수정하고, 실제 빈 줄은 유지합니다.
- UTF-8·CP949 디코더 접두사도 연결 세대와 연속된 바이트 위치를 기준으로 계산합니다. 재연결 전후의 바이트가 다음 페이지에서 하나의 문자로 합쳐지는 문제와 정상 문자 접두사가 유실되는 문제를 수정했습니다.
- 저장된 결과가 없어도 기본 결과 폴더를 열 수 있습니다. 폴더가 삭제됐으면 다시 만들고, 열기에 실패하면 오류를 표시합니다.
- 결과 창을 열어 둔 상태에서도 새 실행 목록을 자동 갱신하고, 창을 다시 활성화할 때도 확인합니다.
- 목록 갱신 중 선택한 실행, RX 상세·페이지와 조회 중인 기록의 보관 보호를 유지합니다. 최근 100개 목록에서 빠진 조회 중 기록도 유지합니다.
- 저장된 결과가 없으면 RX Check 시퀀스를 실행하라는 안내를 표시합니다. 느린 저장소에서는 갱신 요청을 합쳐 중복 조회를 제한합니다.
- 결과 조회와 요약 저장이 겹칠 때 발생하는 일시적인 Windows 파일 잠금은 제한된 시간 동안 재시도합니다. 취소·지속적인 실패는 그대로 처리합니다.
- 단계 목록과 상세 정보에는 날짜를 포함한 밀리초 시각을 표시합니다. RX 로그는 줄이 완성된 수신 시각을 사용하며, 자정을 넘는 TX/RX와 분할 UTF-8 수신을 회귀 검사합니다.
- 명령·검사 패턴은 정의 파일에 한 번 보관하고 실행마다 변하는 값만 축약 JSONL에 저장합니다. 실제 기록기의 축약 저장 경로를 연결하고, 101회 반복 실행에서 파일 생성·페이지 조회·재개방까지 검사했습니다.
- 기존 669건 실행 샘플에서 단계 JSONL은 약 91%, 전체 저장량은 약 80% 줄었습니다. RX 원본, 수신 조각 경계·시각 정밀도, 일치 범위·오류·재시도 정보와 기존 이력 읽기는 유지합니다.
- 손상된 단계·정의·수신 시각 파일은 결과 창에 오류로 표시합니다. 파일 복구 후 프로그램을 종료하지 않고 다시 조회할 수 있는지 검사했습니다.

## 시간 선택기와 로그 필터

- 날짜·시간 항목에서 숫자를 직접 입력할 수 있습니다. 같은 숫자를 연달아 입력하거나 숫자 키패드를 사용하는 경우도 지원하며, 선택 가능한 범위 안에서만 값을 고릅니다.
- 팝업에서 값을 고르는 동안 날짜·시간 목록이 재생성되어 입력이나 포커스가 끊기는 문제를 보완했습니다. 초 선택 항목에서 Enter 또는 Tab으로 이동 버튼에 포커스를 옮길 수 있습니다.
- 로그 필터에 전체 로그·선택한 규칙 수를 표시하고, 규칙 목록과 적용·취소 버튼의 간격 및 한글·영문 안내를 정리했습니다.

## CLI·MCP·플러그인

- 디스크 캡처 메타데이터에서 ID·경로·기본값의 반복 저장을 줄였습니다. CLI/MCP 응답의 기존 필드와 RX 페이지, TX 결과·오류 정보는 그대로 복원합니다.
- MCP 기본 응답은 전체 JSON 텍스트와 구조화 결과를 유지합니다. 구조화 결과를 읽는 최신 클라이언트는 `serialctl mcp --tool-content summary`로 중복 전송을 줄일 수 있으며, 이전 프로토콜의 전체 텍스트 응답은 유지합니다.
- 플러그인과 단독 스킬의 공유 문서를 갱신했습니다. 설치·탐색·CLI 호환 확인과 실제 MCP 시작 검사는 최종 배포 파일로 수행합니다.

## 장치 시험 자료

- STM32용 정상·의도한 타임아웃 RX Check 시퀀스 예제를 추가했습니다.
- NUCLEO-F103RB 시험 펌웨어 1.3.0에 1초 HEARTBEAT와 USER 버튼 누름·뗌 이벤트를 추가하고, 빌드·온보딩 자료를 정리했습니다. 정확한 응답 검사 전에는 `STOP` 또는 `MONITOR OFF`로 배경 출력을 멈춥니다.

## 설치와 검증

- GUI·CLI·설치 프로그램 버전은 1.6.3입니다. 기존 플러그인 1.0.2와 CLI/MCP 제어 API 1.x 호환을 유지합니다.
- 최종 Release 전체 테스트는 Core 475개, WinUI 1,483개를 통과했습니다. 장치 환경이 필요한 조건부 11개 검사는 제외했습니다. 포트 이름 저장의 잠금 복구 검사에서 초기 시간 초과가 한 번 발생했으며, 분리 검사 34개와 WinUI 전체 재실행은 모두 통과했습니다.
- 이번 추가 변경의 Debug 관련 테스트 201개와 단축키·화면 구조 검사를 통과했습니다. RX 페이지 경계의 CRLF, UTF-8·CP949 디코더 접두사, 재연결·바이트 공백과 이전·다음 이동을 회귀 검사했습니다.
- 네이티브·브라우저 단축키 전체 대조와 JavaScript 탐색·화면 구조·기록 메타데이터 검사 31개를 확인했습니다. 배포 패키지의 CLI/MCP 시작 및 플러그인·단독 스킬 구성도 검사합니다.
- 이번 교체본의 검증에는 실장비 조작·수동 GUI·장시간 옵션 내구 시험을 포함하지 않았습니다.
- 설치 프로그램, 포터블, 플러그인, 단독 스킬과 각 SHA-256 체크섬을 제공합니다. 업데이트 전 진행 중인 수집·시퀀스를 마치고 앱과 MCP를 종료하세요.
