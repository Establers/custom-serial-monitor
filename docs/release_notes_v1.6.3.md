# v1.6.3 변경 사항

## 빠른 명령 단축키

- 단축키 입력란을 클릭한 뒤 원하는 키를 누르는 기록 방식으로 바꿨습니다. Esc로 기록을 취소하거나 Clear로 할당을 지울 수 있습니다.
- F1 같은 사용 중이지 않은 단일 키를 지원합니다. 기능키는 명령·검색 입력 중에도 실행할 수 있으며, 문자·숫자 단일 키는 로그 영역에서 사용합니다.
- Enter, Tab, Ctrl+F/G, F3, Shift+F3, Alt+C/W/R 등 기존 기능의 키와 다른 빠른 명령의 키는 중복 등록을 막습니다. 이전 프로필의 충돌·중복 할당도 실행하지 않습니다.
- 네이티브와 브라우저가 공통 단축키 정의를 사용합니다. 새 앱 단축키도 사용자 할당에서 자동으로 보호하며, 정의를 우회하는 키 처리는 빌드 검사에서 확인합니다.
- 키를 누르고 있을 때 로그 영역의 빠른 명령이 반복 전송되지 않도록 했습니다. 비영문 배열의 단일 숫자 키를 보정하고, 조합키·IME·NumLock 동작은 유지합니다.

## 시퀀스 실행 결과

- 결과 창을 열어 둔 상태에서도 새 실행 목록을 자동 갱신하고, 창을 다시 활성화할 때도 확인합니다.
- 목록 갱신 중 선택한 실행, RX 상세·페이지와 조회 중인 기록의 보관 보호를 유지합니다. 최근 100개 목록에서 빠진 조회 중 기록도 유지합니다.
- 저장된 결과가 없으면 RX Check 시퀀스를 실행하라는 안내를 표시합니다. 느린 저장소에서는 갱신 요청을 합쳐 중복 조회를 제한합니다.
- 결과 조회와 요약 저장이 겹칠 때 발생하는 일시적인 Windows 파일 잠금은 제한된 시간 동안 재시도합니다. 취소·지속적인 실패는 그대로 처리합니다.
- 단계 목록, 상세 정보와 TX/RX 타임라인에 날짜를 포함한 밀리초 시각을 표시합니다. 자정을 넘는 TX/RX와 분할 UTF-8 수신 시각을 회귀 검사합니다.

## 장치 시험 자료

- STM32용 정상·의도한 타임아웃 RX Check 시퀀스 예제를 추가했습니다.
- NUCLEO-F103RB 시험 펌웨어 1.3.0에 1초 HEARTBEAT와 USER 버튼 누름·뗌 이벤트를 추가하고, 빌드·온보딩 자료를 정리했습니다. 정확한 응답 검사 전에는 `STOP` 또는 `MONITOR OFF`로 배경 출력을 멈춥니다.

## 설치와 검증

- GUI·CLI·설치 프로그램 버전은 1.6.3입니다. 기존 플러그인 1.0.2와 CLI/MCP 제어 API 1.x 호환을 유지합니다.
- Debug·Release 전체 테스트는 각각 Core 455개, WinUI 1,444개를 통과했습니다. 장치 환경이 필요한 조건부 11개 검사는 제외했습니다.
- JavaScript·실제 Edge 기반 스크립트 23개에서 단축키, 비영문 배열, 백만 줄 보관·300만 줄 기록, 탐색·복원·다중 인스턴스를 검사했습니다.
- 펌웨어 호스트 프로토콜 139개, 코덱·스크립트 검사 20개와 예제 가져오기를 확인했습니다. 이번 최종 릴리스 검증에는 실장비 조작·수동 GUI·장시간 옵션 내구 시험을 포함하지 않았습니다.
- 설치 프로그램, 포터블, 플러그인, 단독 스킬과 각 SHA-256 체크섬을 제공합니다. 업데이트 전 진행 중인 수집·시퀀스를 마치고 앱과 MCP를 종료하세요.
