# Serial Monitor v1.2.1

출시일: 2026-07-26

## 사용성 개선

- 버튼, 입력 필드, 콤보 박스, 탭의 상태와 경계를 더 분명하게 표현해 촘촘한
  화면에서도 조작 대상을 빠르게 구분할 수 있습니다.
- 인스펙터의 여백과 설정 값 표현을 정리해 작은 창에서도 정보 밀도와 가독성의
  균형을 개선했습니다.

## 검색 결과 개선

- 검색 결과를 시간, RX/TX 방향, 메시지 미리보기로 분리해 긴 결과 목록을 더
  빠르게 훑을 수 있습니다.
- 결과 행이 인스펙터 너비를 안정적으로 채우도록 레이아웃과 스크롤 동작을
  다듬었습니다.
- 검색 결과 파싱과 표시 동작을 단위 테스트로 보강했습니다.

## 터미널 가독성과 배포 개선

- JetBrains Mono Regular/Bold WOFF2를 앱에 포함해 대상 PC의 설치 글꼴과
  관계없이 터미널 글꼴과 정렬을 일정하게 유지합니다.
- 포터블 ZIP과 설치 파일에 글꼴, 라이선스, 필수 XAML 리소스가 포함됐는지
  검증하는 절차를 강화했습니다.
- Debug와 Release 구성을 별도 폴더에 만드는 로컬 빌드 스크립트를 추가했습니다.
- Inno Setup 5, 6, 7 탐색과 라이선스 안내를 배포 문서에 반영했습니다.

## 검증

- Release 구성에서 WinUI 테스트 186개와 Core 테스트 35개를 모두
  통과했습니다.
- 포터블 ZIP과 Inno Setup 설치 파일을 Release 구성으로 생성하고 필수 자산과
  SHA-256 체크섬을 확인했습니다.

## 설치 안내

- 설치 파일과 관리자 권한이 필요 없는 포터블 ZIP을 함께 제공합니다.
- 설치 파일은 코드 서명이 없어 Windows SmartScreen에서 알 수 없는 게시자
  경고가 표시될 수 있습니다.
- xterm 로그 화면을 사용하려면 Microsoft Edge WebView2 Runtime이 필요합니다.
