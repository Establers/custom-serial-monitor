# 배경 프리셋

설정의 배경 프리셋 **1~5** 버튼으로 배경을 전환합니다. 마지막으로 누른
번호 하나만 선택됩니다. 선택한 번호에서
찾아보기(`...`)로 이미지를 지정하거나 배경 투명도를 바꾸면 해당 프리셋에만
적용됩니다. 배경 모드 켜기/끄기는 전체 프리셋에 공통입니다.

- 같은 이미지를 앱 배경과 xterm 로그 영역 안에 각각 표시합니다. **앱 배경 투명도**와
  **xterm 배경 투명도**를 0~100%로 독립적으로 조절하며, 두 값 모두 프리셋별로 저장합니다.
  **0%는 이미지를 완전히 표시하고 100%는 이미지를 숨깁니다.** xterm 투명도 100%는
  로그 영역의 이미지만 숨깁니다. 글자, ANSI 강조색, 선택 영역에는
  이미지 투명도가 적용되지 않으며 투명도를 바꿔도 로그나 선택한 텍스트를 지우지 않습니다.
- 창 전체에 맞춘 배경 이미지의 위치·크기를 xterm과 공유하므로, 로그 영역에서도
  같은 그림의 해당 부분이 이어져 보입니다. 창 크기 변경이나 아래 패널 접기에도
  배치를 맞춥니다. 두 투명도는 독립적이므로 영역별로 보이는 진하기는 다를 수 있습니다.
  이미지가 없거나 읽기에 실패하면 로그 영역은 기존 단색 배경을 사용합니다.
- 기존 앱 배경의 보이는 정도는 유지하고 표시값만 투명도로 환산합니다(기존 불투명도
  25% → 투명도 75%). xterm 배경 투명도의 기본값은 **85%**이며
  고대비 모드에서는 xterm 이미지를 숨기고 기존 고대비 색상을 사용합니다.
- 기존 배경 이미지와 설정은 **1번**으로 이전합니다. 2~5번은 비어 있으며
  앱 배경 투명도 기본값은 75%입니다. 빈 프리셋은 내장 기본 배경을 표시합니다.
- 이미지 선택 시 원본을 복사하고 프로필을 즉시 저장합니다. 이후 원본 파일을
  이동하거나 삭제해도 배경이 유지됩니다. 기존 배경도 파일에 접근할 수 있으면
  프로필을 읽을 때 자동으로 복사하고 저장합니다.
- PNG, JPG, JPEG, WebP 파일을 지원하며 이미지 하나의 크기는 최대 20 MB입니다.
- 번호 선택은 즉시 저장합니다. 두 배경 투명도 변경은 기존 설정과 동일하게 프로필
  저장 또는 정상 종료 시 저장합니다.
- 초기화 버튼은 선택한 번호의 이미지만 비웁니다. 다른 번호의 이미지와
  두 배경 투명도는 유지합니다.
- 원본을 이미 삭제하여 접근할 수 없다면 이미지를 복구할 수 없습니다.
  해당 번호의 경로를 유지하고 내장 배경을 표시하므로 찾아보기로 다시 지정하세요.

기본 프로필은 `%LOCALAPPDATA%\SerialMonitor\profiles\default.json`이며,
선택 번호와 번호별 이미지 경로·앱 배경 투명도·xterm 배경 투명도를 저장합니다. 이미지 사본은 옆의
`default.json.backgrounds` 폴더에 `preset-1.png` 등의 이름으로 보관합니다.
같은 번호·확장자를 다시 지정하면 기존 사본을 교체하여 파일이 계속 쌓이지
않습니다. 다른 확장자로 교체한 이전 사본은 보관되며, 보관 파일 수는
프로필당 최대 20개(5개 번호 × 4개 확장자)로 제한됩니다.

프로필을 백업하거나 다른 PC로 옮길 때는 JSON과 `.backgrounds` 폴더를 함께
보관하세요. 현재 이미지 경로는 절대 경로이므로 다른 위치로 옮긴 경우 각
번호에서 보관한 이미지를 다시 선택해야 합니다. 앱만 제거하거나 재설치해도
기본 사용자 데이터 폴더의 프로필과 이미지 사본은 유지됩니다.

## 개발 검증

WebView2의 [가상 호스트 등록 제약](https://learn.microsoft.com/en-us/dotnet/api/microsoft.web.webview2.core.corewebview2.setvirtualhostnametofoldermapping#remarks)에 따라
이미지 호스트는 페이지 탐색 **전에** 등록합니다. 내장 배경과
프로필의 `.backgrounds` 폴더를 각각 고정 호스트로 등록하고, 이미지 전환 시에는
URL만 바꿉니다. 페이지가 열린 후에 새 호스트를 추가하면 이미지가 로드되지 않을
수 있으므로 브라우저의 모의 네트워크 검사만으로 이 경로를 검증하지 않습니다.

PowerShell 7과 일반 대비 모드의 Windows 데스크톱에서 실제 WinUI 빌드를 검사합니다.
앱을 한 번 실행해 기본 프로필이 생성되어 있어야 합니다.

```powershell
pwsh -NoProfile -File scripts/test_xterm_background_native.ps1 -AppPath artifacts/build/Release/SerialMonitor.WinUI.exe
```

검사 도구는 별도 검증용 앱을 잠시 실행하고 .NET 시작 훅으로 해당 프로세스만
제어합니다. 장비에 연결하거나 데이터를 전송하지 않고 프로필을 저장하지 않습니다.
페이지 로드 후에 한글·공백·`#`가 포함된 임시 이미지를 만들어 전환하고,
내장/사용자 이미지, 투명도 0·50·100%, 배경 끄기, 표시 로그 보존을 검사합니다.
추가로 XAML 배경을 `RenderTargetBitmap`으로 캡처하고 실제 WebView2 픽셀과 비교해
초기 배치·두 가지 창 크기·패널 접기 상태에서 그림의 위치와 크기가 맞는지 검사합니다.
종료 시 임시 이미지와 검증 프로세스를 정리하고 프로필 해시가 그대로인지 확인합니다.
상태 JSON과 실제 WebView2 PNG 캡처는 `artifacts/native-background-smoke` 아래에 남깁니다.
