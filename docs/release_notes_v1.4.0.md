# Serial Monitor v1.4.0

## 업데이트 알림

- About에서 설치 버전, 최신 버전 확인 결과와 마지막 확인 시각을 볼 수 있습니다.
- 시작 후 자동으로 GitHub의 정식 릴리스를 확인하며, 최근 확인 시도를 기준으로 하루 간격을 둡니다. 자동 확인 끄기와 수동 확인을 지원합니다.
- 새 버전이 있으면 하단에 작은 알림을 표시합니다. 작업 화면을 자동 전환하거나 로그 위에 팝업을 띄우지 않습니다.
- 특정 버전의 알림을 건너뛸 수 있으며, 확인 결과와 설정은 앱을 다시 실행해도 유지됩니다.
- 업데이트 보기를 누르면 GitHub 릴리스 페이지가 열립니다. 다운로드와 설치는 수동이며, 자동 설치나 재시작은 하지 않습니다.

## 안정성과 사용성

- 업데이트 네트워크 요청과 설정 파일 처리를 UI 스레드에서 분리했습니다. 시리얼 수신과 로그 처리는 업데이트 완료를 기다리지 않습니다.
- 여러 창에서 설정을 저장할 때 변경한 필드만 병합하고, 프로세스 간 파일 잠금과 고유 임시 파일로 저장 충돌을 방지합니다.
- 다른 창에서 확인한 새 버전 캐시와 건너뛰기 설정을 다시 읽을 때 알림 상태도 갱신합니다.
- 런타임 진단 파일 기록을 백그라운드로 옮겼습니다.
- 명령 기록 검색과 도구 모음 사용성을 개선했습니다.

## 배포

- Release 전체 솔루션 빌드와 자동 테스트 557개(Core 35개, WinUI 522개)를 통과했습니다. 실제 장비 장시간 실행과 설치 UI 검증은 이번 검증에 포함하지 않았습니다.
- Windows 10/11 x64용 설치 EXE, 포터블 ZIP 및 SHA-256 체크섬을 제공합니다.
- Microsoft Edge WebView2 Runtime이 필요합니다.
- 업데이트 알림은 이 기능이 포함된 v1.4.0부터 사용할 수 있습니다. 이전 정식 버전 사용자는 이번 버전을 직접 다운로드해 설치해 주세요.
