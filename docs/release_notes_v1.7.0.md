# v1.7.0 변경 사항

2026-11-16 배포본입니다. Modbus 장치 감시·제어와 장치 시뮬레이터, 로그 룰 공유·정규식, 패널 도킹을 추가했습니다. 화면 로그 보관과 콘솔 입력, 검색 결과도 개선했습니다.

## Modbus 장치 감시·제어

- 여러 장치의 코일·입력·레지스터 영역을 읽기 그룹으로 저장하고, 선택한 그룹을 한 번 읽거나 포함된 그룹을 자동으로 읽을 수 있습니다.
- 이름·자료형·배율·바이트/워드 순서·읽기/쓰기 권한을 가진 항목을 정의합니다. 쓰기 전 장치 ID와 주소 범위를 확인하며, 여러 레지스터로 이루어진 항목의 일부만 쓰지 않도록 검사합니다.
- 저장한 제어 명령을 실행하고 응답 확인, 값 재읽기, 지정 상태 조건으로 결과를 확인할 수 있습니다. 쓰기 응답 수신과 실제 값 확인 결과를 구분합니다.
- 읽기 실패는 다른 그룹의 감시를 이어가며 간격을 두고 복구합니다. 완료 여부가 불명확한 쓰기를 자동으로 다시 보내지 않습니다.
- 통신 작업이 포트를 점유하는 동안 다른 송신·설정 변경이 끼어들지 않도록 하고, 연결이 바뀌면 이전 작업과 응답을 구분합니다.
- 장치 선택, 읽기 설정, 항목·명령 편집과 패킷 상세의 용어·드롭다운·버튼·여백을 통일했습니다.

## 장치 시뮬레이터와 통신 모니터링

- JSON으로 장치 ID, 메모리 영역, 기본값을 정의해 Modbus 장치 응답을 시험할 수 있습니다. 제품 정의를 저장·복사·가져오고 실행 중 값을 변경하거나 기본값으로 복원할 수 있습니다.
- 읽기·쓰기와 FC22 마스크 쓰기, FC23 읽기/쓰기, FC24 FIFO 요청을 지원합니다. 배포본에 EE071 예제를 제공하며, 저장소에는 Nucleo F103RB 시험 펌웨어와 명령 프리셋을 추가했습니다.
- 통신 모니터링에서도 수동 TX와 시퀀스를 사용할 수 있습니다. PC가 송신한 데이터는 TX, 선로에서 받은 데이터는 RX로 표시합니다.
- 시뮬레이터 조작부는 좁은 패널에서 줄을 나누고, 넓은 화면에서도 관련 컨트롤이 함께 배치됩니다.
- 응답 도중 연결이 끊기거나 재연결되면 같은 수신 묶음에 남아 있는 쓰기·브로드캐스트도 폐기해 이전 실행의 값이 뒤늦게 바뀌지 않도록 했습니다.

## 로그 룰 공유·정규식

- 룰을 공유 텍스트로 내보내고 붙여넣어 가져옵니다. 기존 룰은 유지하며 같은 설정의 중복은 제외합니다. 시퀀스에 연결된 룰은 확인 후 켤 수 있도록 비활성 상태로 가져옵니다.
- Terminal 룰에 정규식을 추가했습니다. 완성된 논리 줄을 기준으로 검사하며 패턴·입력 길이와 실행 시간을 제한합니다. 16,384자를 넘는 줄은 건너뛰고, 지원하지 않는 패턴은 저장 전에 안내합니다.
- 같은 RX 줄이 여러 내부 조각으로 들어와도 문자열·HEX 패턴을 이어서 검사하고, 일치한 줄의 보관 중인 앞뒤 내용을 필터에 표시합니다. 실제 줄 구분·연결 변경·수신 누락은 넘어서 연결하지 않습니다.
- 이름·패턴이 같은 룰도 알림 방식이나 간격이 다르면 각각 처리합니다.

## 패널·검색·콘솔

- 탭 패널을 드래그해 왼쪽·오른쪽·하단에 붙이고 크기·접힘 상태를 저장합니다. 도킹과 창 크기 변경 시 터미널 크기 재계산을 제한하고 중단된 드래그 상태를 해제합니다.
- 검색 결과의 상태·미리보기·원본 이동을 정리했습니다. 명시적 검색은 다시 실행하고, 실패 안내는 새 로그가 들어와도 유지합니다.
- 콘솔 입력의 Enter·Backspace 전송 방식, 로컬 에코, 수신 개행 보정을 한 메뉴에서 설정합니다. 자동 줄바꿈과 이모지 입력 시 커서 위치도 보완했습니다.
- 화면 로그 메모리 예산은 기본 256 MiB이며 64–2048 MiB 범위에서 설정합니다. 보관 한도에 도달하면 오래된 앞부분부터 줄이고, 디스크 전체 로그 기록은 계속합니다.
- 종료 시 창을 먼저 닫고 정리를 이어갑니다. 로그 파일의 저장 누락이나 미확정 기록은 종료 진단에 남깁니다.

## 배포와 검증 범위

- GUI·CLI·설치 프로그램 버전은 1.7.0입니다. 설치형, 포터블, 플러그인, 기존 단독 스킬 ZIP과 SHA-256 체크섬을 제공합니다.
- 플러그인 버전 1.0.3과 CLI/MCP 제어 API 1.x 호환을 유지합니다.
- Release 솔루션 빌드는 경고·오류 0개이며, Core 781개와 WinUI 2,543개 검사에 통과했습니다. 장치·드라이버 환경이 필요한 19개는 제외했습니다.
- 터미널·로그 보관·검색·직접 입력·단축키 회귀 검사, 펌웨어 프로토콜 5,871개 검사, 플러그인 22개 및 스킬 설치·경로 20개 검사를 통과했습니다.
- 배포 파일의 버전·필수 자산·플러그인/CLI 호환성과 SHA-256 체크섬을 검사했습니다.
- 이번 릴리즈 통합 검증에서는 실물 UART·RS-485와 장시간 연속 운전을 다시 시험하지 않았습니다. 이전 기능별 실장치 검증 기록과 자동 회귀 검사는 구분합니다.
- 업데이트 전 진행 중인 수집·시퀀스를 마치고 앱과 MCP를 종료하세요. 사용자 로그·프로필·제품 정의와 AI 클라이언트 설정은 유지합니다.
