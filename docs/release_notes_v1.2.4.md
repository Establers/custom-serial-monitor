# Serial Monitor v1.2.4

출시일: 2026-07-30

## Search와 Event 표시 개선

- Search Results와 Event 목록에서 실제로 일치한 문자열을 색으로 구분합니다.
- Search Results는 같은 로그 줄의 반복 occurrence를 `×N` 한 행으로 묶습니다.
- 일치 로그가 1,000줄을 넘으면 과거에서 최신 방향으로 페이지를 이동할 수
  있으며, 최신 페이지의 Next는 새 로그를 포함해 검색을 갱신합니다.
- F3와 Shift+F3는 페이지와 무관하게 전체 검색 snapshot의 개별 occurrence를
  계속 탐색합니다.

## 룰과 명령 시퀀스 자동화

- 룰 목록의 행을 더블 클릭하면 편집 창이 열립니다. 빈 영역, 스크롤바,
  체크박스와 행 내부 버튼의 더블 클릭은 편집으로 처리하지 않습니다.
- RX 룰이 감지되면 선택한 비어 있지 않은 명령 시퀀스를 한 번 실행할 수
  있습니다.
- 트리거는 UI 이벤트 큐와 분리된 bounded 제어 채널로 전달되므로 이벤트 화면이
  밀리는 상황에서도 첫 실행 요청을 보존합니다.
- 시퀀스가 실행 중일 때 발생한 후속 트리거는 중복 실행하지 않고 병합합니다.
- TX-only 룰, 빈 시퀀스, 누락된 시퀀스 참조는 선택·편집·프로필 로드 단계에서
  차단하거나 정규화하고 진단을 남깁니다.

## 시퀀스 반복과 프로필

- 명령 시퀀스 전체를 1~99회 반복할 수 있습니다.
- 반복 횟수와 룰의 트리거 시퀀스 선택은 JSON 프로필에 저장됩니다.
- 시퀀스 이름을 변경하거나 삭제하면 연결된 룰 참조도 함께 갱신됩니다.
- 새 환경에서 기본 프로필 파일이 없으면 시작 시 자동으로 생성합니다.
- 중복 시퀀스 이름과 잘못된 반복 횟수는 안전한 값으로 정규화합니다.

## 안정성과 성능

- 트리거 전용 이벤트는 일반 UI 이벤트 큐와 하이라이트 segment 생성 비용을
  사용하지 않습니다.
- Search Results는 페이지당 최대 1,000개 로그 줄만 UI 객체로 생성합니다.
- 이벤트 문맥, UI 로그, 검색 결과와 시퀀스 트리거 경로는 기존 bounded 설계를
  유지합니다.

## 검증

- Core 테스트 35개와 WinUI 테스트 262개, 총 297개를 통과했습니다.
- 경고를 오류로 처리한 빌드를 경고 0개, 오류 0개로 완료했습니다.
- 포터블 ZIP과 Inno Setup 설치 파일을 Release 구성으로 생성하고 SHA-256
  체크섬을 함께 제공합니다.

## 설치 안내

- 설치 파일과 관리자 권한이 필요 없는 포터블 ZIP을 함께 제공합니다.
- 설치 파일은 코드 서명이 없어 Windows SmartScreen에서 알 수 없는 게시자
  경고가 표시될 수 있습니다.
- xterm 로그 화면에는 Microsoft Edge WebView2 Runtime이 필요합니다.
