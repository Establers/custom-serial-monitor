# v1.6.4 변경 사항

2026-11-08 배포본입니다. 직접 터미널 입력, Modbus RTU·BACnet MS/TP 분석, 배경 프리셋과 시리얼 연결 진단을 추가하고, AI 제어의 캡처 복구와 공용 제품 메모리를 보완했습니다.

## 직접 터미널 입력

- 로그 영역에서 장치 셸로 직접 입력할 수 있습니다. 콘솔 제어 문자와 로컬 에코를 처리하고, 입력 상태를 화면에 표시합니다.
- 직접 입력과 일반 명령 전송의 순서를 유지하고, 직접 입력을 중지하면 대기 중인 드라이버 설정 변경을 취소합니다.
- 직접 입력 화면의 수신 표시·검색·전송 이력과 시퀀스 동작을 맞추고, 화면 전환 시 터미널 로그를 보존합니다.

## 프로토콜 분석과 연결 진단

- Modbus RTU와 BACnet MS/TP 프레임을 선택적으로 분석합니다. 최근 프레임은 제한된 메모리에 보관하고, CRC·오류 통계와 패킷 상세를 제공합니다.
- 프로토콜 목록 일시정지, 필터와 비우기를 지원하고, BACnet 상세 화면에서 패킷 바이트를 구분해 표시합니다.
- 연결 실패 원인을 설명하고, 확인 가능한 경우 포트를 사용하는 프로세스를 표시합니다. 포트 소유자 조회는 별도 작업 프로세스와 제한 시간으로 처리합니다.
- 연결 중 시리얼 설정과 제어선 변경을 순서대로 처리합니다. HEX 자동 타임아웃은 프레임 전송 시간을 반영하고, RX 점유율은 제한된 수신 구간을 기준으로 계산합니다.
- STM32 시험 펌웨어에 Modbus RTU 응답, BACnet MS/TP 시험 자료와 검증 시퀀스를 추가했습니다.

## 배경과 화면 설정

- 다섯 개의 독립 배경 프리셋에 이미지와 자르기 위치를 저장합니다. 이미지는 비율을 유지하며 화면을 채웁니다.
- xterm 로그에도 공통 배경을 표시하고, 로그 영역 투명도를 별도로 조절합니다. 창과 터미널의 이미지 자르기 위치를 맞췄습니다.
- 밝은 테마의 메뉴 배경, 빠른 툴팁과 시리얼 설정 안내, 로그·브리지·프로토콜 설정 배치를 정리했습니다.
- 자동 로그 파일명 앞에 저장된 창 이름을 붙입니다.
- 배포 검사에서 누락되거나 오래된 터미널 HTML·JavaScript·기본 배경 이미지를 거부합니다.

## CLI·MCP·AI 플러그인

- CLI 또는 MCP 응답을 받지 못했을 때 보관된 캡처를 다시 찾아 실제 RX와 전송 결과를 확인할 수 있습니다.
- MCP 호스트의 출력 연결이 끊기면 플러그인 실행기도 종료해 남은 프로세스를 줄입니다.
- 같은 Windows 사용자의 `%LOCALAPPDATA%\SerialMonitor\Notes`에 공용 Markdown 제품 메모리를 둡니다. 장치 작업 전에 제품 식별 정보·프로토콜·이전 시험 근거를 읽고 재사용하도록 공유 가이드를 갱신했습니다.
- Plugin 빠른 시작 하단에서 공용 메모리 폴더를 열 수 있습니다. 기존 노트와 사용자 양식을 보존하며 초기 파일을 준비합니다.
- 플러그인 버전은 1.0.3이며 CLI/MCP 제어 API 1.x 호환을 유지합니다. 기존 플러그인 사용자는 AI 호스트에서 플러그인을 업데이트하거나 다시 로드하세요.

## 설치와 검증

- GUI·CLI·설치 프로그램 버전은 1.6.4입니다. 설치 프로그램, 포터블, 플러그인, 단독 스킬과 각 SHA-256 체크섬을 제공합니다.
- Release 전체 빌드는 경고·오류 0개이며, Core 595개와 WinUI 1,692개 테스트를 통과했습니다. 실제 장치·가상 COM 환경이 필요한 조건부 검사 17개는 건너뛰었습니다.
- 네이티브·브라우저 단축키 대조, 로그 탐색·배경·직접 입력·로컬 에코 검사와 단독 스킬 설치·경로 검사 20개를 통과했습니다. C# 수신 경로가 내보낸 실제 디코딩 결과와 브라우저 화면 검색의 호스트 일치 결과도 교차 확인했습니다.
- 업데이트 전 진행 중인 수집·시퀀스를 마치고 앱과 MCP를 종료하세요. 앱 설치가 AI 클라이언트 설정이나 플러그인 캐시를 자동 변경하지는 않습니다.
- 공용 메모리와 COM3 보드의 짧은 기능 시험 결과는 [검증 기록](https://github.com/Establers/custom-serial-monitor/blob/v1.6.4/docs/agent-memory-validation.md)에 있습니다. 이 기록은 장기 안정성 시험을 의미하지 않습니다.
