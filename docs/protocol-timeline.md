# Protocol 목록의 시간순 표시

Protocol 목록은 프레임의 관측 시각이 오래된 것부터 아래로 표시한다. RX/TX 분석기가
프레임 조립을 마친 순서는 화면 순서로 사용하지 않는다. 따라서 TX 요청보다 나중에 받은
RX 응답이 먼저 해석되어도 요청 위에 남지 않는다. 관측 시각이 같은 프레임은 분석 결과
ID 순서로 유지한다. 시각은 날짜를 포함하여 비교하며, 표에는 밀리초까지 표시한다.

뒤늦게 해석된 과거 프레임은 해당 시각의 위치에 넣는다. 선택한 프레임과 상세는 ID로
유지한다. 표시 일시정지 중에는 고정된 스냅샷만 정렬하고, 재개하면 새 결과를 합친다.
필터·탭 복원에도 같은 정렬을 적용한다. 보관 한도와 분석 ID·누적 통계는 그대로 유지한다.

HEX 로그와 Protocol RX는 같은 입력 조각의 수신 관측 시각을 공유한다. HEX 묶음의
시각은 첫 입력 조각의 시각이며, idle 대기·큐 지연 후 화면 문자열을 만든 시각이 아니다.
큰 HEX 묶음을 메모리 제한 때문에 여러 세그먼트로 내보내도 묶음 시작 시각을 유지한다.
여러 프레임이 하나의 HEX 묶음에 있으면 Protocol은 각 프레임의 시작 조각 시각을 쓴다.
한 입력 조각 안의 개별 바이트별 선로 시각은 추정하지 않는다. Terminal 텍스트 줄의
시각 처리에는 변경이 없다.
