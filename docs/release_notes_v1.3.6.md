# Serial Monitor v1.3.6

## UI와 검색

- 촘촘한 배치를 유지하면서 도구 모음, 각 탭, 편집 창의 간격과 정렬을 맞췄습니다. 패딩과 간격은 늘리지 않았습니다.
- 검색 입력란 오른쪽, 이전 결과 버튼 왼쪽에 돋보기 검색 버튼을 추가했습니다. Enter와 동일하게 현재 옵션으로 검색을 갱신하고 다음 결과를 선택합니다.
- 한 줄 설명의 표시 방식과 툴팁을 보완했습니다.
- 단어 단위 검색에서 앞의 후보가 불일치할 때 뒤의 겹치는 정상 일치를 놓치던 문제를 수정했습니다.
- 대소문자 구분, 단어 단위, 정규식 옵션의 8가지 조합과 결과 탐색을 자동 테스트로 검증했습니다.

## 설정과 안정성

- 시스템 설정 따르기, 어두운 테마, 밝은 테마 선택을 추가하고 프로필에 저장합니다.
- Terminal/HEX 전환 시 화면 로그와 검색 결과를 초기화합니다. 기존 파일 로그는 보존하고 파일 기록은 계속합니다. HEX 타임아웃만 변경할 때는 화면 로그를 지우지 않습니다.
- 모드 전환 전에 대기하던 브리지 화면 로그가 뒤늦게 나타나지 않도록 처리했습니다.
- 이벤트 감지 작업이 실패하거나 취소되면 입력과 출력 채널 및 대기 상태를 정리해, 종료된 작업에 로그가 쌓이지 않도록 수정했습니다.

## 배포

- Debug와 Release에서 각각 전체 자동 테스트 413개를 통과했습니다.
- Windows 10/11 x64용 Release 빌드의 설치 EXE와 포터블 ZIP, 각각의 SHA-256 체크섬을 제공합니다.
- Microsoft Edge WebView2 Runtime이 필요합니다.
- 실제 장비의 장기간 연속 실행 및 모든 탭의 실행 화면 검증은 이번 릴리즈 검증에 포함되지 않았습니다.
