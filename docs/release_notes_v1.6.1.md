# v1.6.1 변경 사항

## 로그 탐색과 검색

- 로그 화면에 시간 레일을 추가했습니다. `Ctrl+G` 또는 우클릭 메뉴에서 시간·줄 번호·비율로 이동하고 이전 위치로 돌아갈 수 있습니다.
- 수신 시각을 숨긴 상태에서도 내부 시간 메타데이터를 유지하여 시간 이동과 검색 결과 시각을 표시합니다. 타임스탬프 표시 형식도 추가했습니다.
- 검색 결과의 Enter 및 F3/Shift+F3 이동이 결과 페이지와 원본 로그 선택을 함께 갱신합니다. 이벤트를 더블클릭하면 보존된 원본 로그로 이동합니다.
- 검색 중 수신된 로그, 조건 변경, 오래된 요청의 결과를 구분하여 검색 상태와 선택이 뒤섞이지 않도록 했습니다.
- 시간 탐색은 보존된 로그 범위에서 동작하며 압축된 과거 로그의 스캔과 캐시 사용을 제한합니다.

## 로그 필터와 설정

- 화면 필터를 기존 보존 로그와 새 수신 로그 모두에 적용합니다. `ALL`을 선택하면 보존 한도 안의 숨겨진 로그를 다시 표시합니다. 이벤트·하이라이트 규칙 변경은 새 로그에 적용됩니다.
- 파일 기록이 OFF인 동안 저장 폴더를 변경할 수 있으며 다음 기록 시작 시 재연결 없이 적용합니다. 폴더 쓰기 가능 여부는 UI를 막지 않고 검사합니다.
- 로그 규칙 편집 창과 도움말을 정리하고, 알림 간격 범위를 5초~24시간으로 통일했습니다.

## 명령 시퀀스

- 단계별 활성화·비활성화, 단계 복제와 시퀀스 복제를 추가했습니다. 비활성 단계는 정의에 보존되며 실행에서는 제외됩니다.
- 실행 버튼으로 단계 경계에서 일시정지·재개할 수 있습니다. 일시정지는 현재 송신과 지연이 끝난 뒤 적용되며 Stop은 실행을 취소합니다.
- 단계 편집에서 Terminal/HEX/Global TX 모드를 선택할 수 있습니다. 실행 시작 시 설정을 스냅샷으로 고정하고 원래 단계 번호를 유지합니다.

## AI 플러그인

- 함께 제공하는 `serial-monitor` 플러그인을 **1.0.1**로 갱신했습니다. MCP 클라이언트가 입력 스트림을 계속 열어 둔 상태에서 응답을 기다릴 때 초기화가 멈출 수 있던 버퍼링 문제를 수정했습니다.
- 기존 플러그인은 사용하는 AI 도구의 플러그인 갱신·재로드 절차로 업데이트하세요. 최소 CLI 버전은 1.6.0, 제어 API는 1.x로 유지됩니다.

## 배포 파일

- `SerialMonitorSetup.exe`: Windows x64 일반 설치
- `SerialMonitorPortable.zip`: Windows x64 포터블 프로그램과 플러그인 원본
- `SerialMonitorPlugin.zip`: 플러그인 원본 별도 배포
- `SerialMonitorSkills.zip`: 기존 단독 skill 호환 설치
- 각 파일에 SHA-256 체크섬을 제공합니다.

## 검증

- Debug·Release 빌드: 경고 0개, 오류 0개
- Debug·Release 각각 자동 테스트 1,152개 통과. 가상 COM 포트 쌍을 지정해야 하는 5개 테스트는 기본 환경에서 건너뜁니다.
- 실제 Edge에서 시간 탐색·검색·Back·크기 변경·타임스탬프 숨김·빈 초기 화면·테마 격리를 확인했습니다.
- 보존 로그 100만 행과 과거 로그 캐시 제한, 열린 stdin을 사용하는 MCP 초기화, 플러그인·단독 skill 패키징 검증을 통과했습니다.
- 포터블 프로그램의 실행·상태 조회·정상 종료를 확인했습니다. 실제 장치 UART 동작은 이번 릴리즈 검증 범위에 포함하지 않습니다.
