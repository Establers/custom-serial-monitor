# Serial Monitor v1.5.0

2026-10-25

## AI CLI / MCP 제어

- 실행 중인 GUI의 COM 연결을 사용하는 `serialctl` CLI와 선택적 로컬 MCP 서버를 제공합니다. 포트 조회·연결, 저장 명령 조회, 명령 전송, RX 수집·페이지 조회·중지를 지원합니다.
- 명령을 한 번 보낸 뒤 지정한 시간 동안 들어온 전체 RX를 수집합니다. printf가 섞인 출력도 실제 수신 순서로 보존하며, 제품 성공 여부는 응답 내용을 읽고 판단할 수 있습니다.
- 큰 응답은 파일에 보관하고 제한된 크기의 페이지로 반환합니다. `--preview-bytes`로 첫 페이지를 줄일 수 있고, `--text-file`로 따옴표·공백·줄바꿈을 보존해 명령을 전달할 수 있습니다.
- GUI의 MCP 탭에서 클라이언트별 등록법과 사용 예시를 확인할 수 있습니다. 하단의 AI 제어 상태와 중지 버튼도 제공합니다.

## 별도 설치하는 공통 스킬

- Codex·Claude Code·GitHub Copilot에서 사용할 `serial-monitor-control` 스킬을 **`SerialMonitorSkills.zip`으로 별도 배포**합니다. 프로그램은 따로 설치하고, 스킬 설치 시 기존 프로그램의 CLI 경로를 지정합니다.
- 스킬 ZIP에는 설치 스크립트와 한글 설치 안내, CLI·MCP 가이드가 포함됩니다. 프로그램 EXE와 사용자별 설정은 포함하지 않습니다.
- README 상단에서 프로그램 설치 EXE, 포터블 ZIP, 스킬 ZIP을 각각 바로 다운로드할 수 있습니다. 앱의 MCP·About 탭에도 스킬 소개와 설치 안내를 추가했습니다.

## 안정성 및 사용성 개선

- Bridge 시작 중에도 AI 제어와 충돌하지 않도록 제어권을 잠급니다. AI 연결 중 GUI 연결 변경을 막고, 실제 연결된 포트·baud를 검증합니다.
- 연결 준비·대기·포트 열기 단계에 요청 취소를 전달합니다. 수집 취소·오류 시에도 가능한 부분 RX와 TX 상태를 보존합니다.
- 읽기 중인 과거 캡처 파일은 정리 대상에서 건너뛰어 새 캡처와 기존 데이터 조회가 실패하지 않도록 했습니다.
- 검색에 F4 이전 결과 이동을 추가하고, 줄바꿈이 끝나지 않은 RX·탭만 있는 RX·화면 복원 이후의 검색 위치 계산을 보완했습니다.
- 배경 불투명도를 0~100%로 조절하고, 일시적으로 접근할 수 없는 배경 이미지 경로를 유지합니다. 종료 시 연결 정리보다 먼저 프로필 저장을 시도합니다.

## 배포

- `SerialMonitorSetup.exe`: Windows 10/11 x64용 일반 설치 파일
- `SerialMonitorPortable.zip`: 프로그램 포터블 배포
- `SerialMonitorSkills.zip`: 스킬 전용 설치 패키지
- 각 파일의 `.sha256` 체크섬을 제공합니다. 로그 화면에는 Microsoft Edge WebView2 Runtime이 필요합니다.

## 검증

- Debug·Release 전체 솔루션 빌드와 자동 테스트 693개(Core 70개·WinUI 623개)가 두 구성에서 각각 통과했습니다.
- 스킬 ZIP 생성·압축 해제·세 도구 설치를 포함한 검증 11개와 xterm 큐 테스트 8개가 통과했습니다.
- 격리된 headless Edge에서 수신 중 검색 위치 유지, 미완성 RX·탭·화면 복원 이후 검색, F3/Shift+F3/F4 단축키를 검증했습니다.
- 실제 COM 장치 및 장시간 하드웨어 동작은 이번 자동 검증에 포함하지 않았습니다.
