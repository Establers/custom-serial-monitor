# Serial Monitor v1.4.1

## 수정 사항

- GitHub API 요청 제한으로 업데이트 확인이 실패할 때 GitHub Pages에 게시된 최신 릴리스 정보로 다시 확인합니다. 제한이 풀릴 때까지 API 재시도를 줄이고, 두 경로에 공통 시간 제한을 적용합니다.
- 같은 TX 명령을 다시 전송하면 기록의 맨 위로 이동하고 마지막 전송 시각을 갱신합니다. 위/아래 방향키로 최근 전송 순서대로 탐색하며, 저장 후 다시 불러온 기록에도 이 순서를 유지합니다.
- 반복 명령의 기록 용량 관리와 업데이트 확인 대체 경로에 대한 회귀 테스트를 추가했습니다.

## 배포

- Release 전체 솔루션 빌드(경고·오류 0개)와 자동 테스트 575개(Core 35개, WinUI 540개)를 통과했습니다.
- Windows 10/11 x64용 설치 EXE, 포터블 ZIP 및 SHA-256 체크섬을 제공합니다.
- Microsoft Edge WebView2 Runtime이 필요합니다.
- 실제 장비 장시간 실행과 설치 UI 검증은 이번 검증에 포함하지 않았습니다.
