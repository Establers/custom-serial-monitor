# Serial Monitor v1.3.5

## 대량 로그와 복원 안정성

- 기본 및 최대 로그 보관량을 100만 줄로 늘렸습니다. 기존 프로필은 설정을 유지하므로 필요하면 Line scrollback을 1000000으로 변경하세요.
- 오래된 터미널 행을 메모리에서 무손실 압축하고 중복 보관을 줄였습니다. 100만 행 시험에서 화면 엔진의 보관 메모리는 약 79% 감소했습니다. 앱 전체 메모리 감소율은 아니며, 데이터 길이와 색상에 따라 사용량이 달라집니다.
- 대량 입력 중 로그 화면 복원·다시 그리기가 반복되던 문제를 수정했습니다. 복원 중 중복 재시도를 막고 작은 묶음 단위로 전송·완료 확인합니다.
- 밀린 화면 업데이트를 제한된 큐에 유지하고, 처리된 전송 텍스트는 즉시 해제합니다.

## 복원 진행 표시

- 복원 화면에 진행 막대와 퍼센트, 경과 시간, 예상 남은 시간을 표시합니다.
- 진행률은 화면 엔진이 실제로 처리한 양으로 계산합니다. 초기 예상 시간은 계산 중으로 표시하며 처리 속도에 따라 달라질 수 있습니다.

## 배포 및 검증

- Windows 10/11 x64용 설치 EXE와 포터블 ZIP, 각 파일의 SHA-256 체크섬을 제공합니다.
- Microsoft Edge WebView2 Runtime이 필요합니다.
- 정식 배포는 Release 빌드입니다. Mock Test는 Debug 빌드에서 사용할 수 있습니다.
- 자동 파일 저장을 추가하지 않았습니다. 파일 저장이 OFF인 경우 종료하면 메모리에 보관된 로그는 사라집니다.
- 테스트 방법과 측정 범위는 [이력 보관 검증](history-retention-validation.md), [복원 반복 문제 검증](xterm-recovery-validation.md)을 참고하세요. 수주간 실장비 연속 실행을 검증했다는 의미는 아닙니다.
