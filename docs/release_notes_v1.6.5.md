# v1.6.5 변경 사항

2026-11-10 배포본입니다. Modbus RTU 요청 패킷 생성과 응답 값 해석을 추가하고, 프로토콜 목록의 시간순 표시와 HEX 복사를 개선했습니다.

## Modbus RTU 패킷 만들기

- Protocol 탭에서 Modbus RTU를 선택한 뒤 `패킷 만들기`를 열 수 있습니다. 연결 전에도 요청을 작성하고 CRC가 포함된 HEX를 복사할 수 있습니다.
- 읽기·쓰기, 진단, 파일 레코드, 마스크 쓰기, 복합 읽기/쓰기, FIFO, 장치 식별 등 표준 요청 19종과 Custom PDU를 지원합니다.
- 기능별 수량·주소·값·프레임 크기를 검증하고, 여러 코일의 비트 배치와 수량·바이트 수·CRC를 자동 계산합니다. 긴 입력을 잘라 다른 장치 ID나 주소로 바꾸지 않습니다.
- 복사와 닫기는 WinUI 기본 버튼을 사용합니다. 명령별 입력 배치를 압축하고, 스크롤바 여백과 고정 HEX 미리보기를 적용했습니다.
- 클립보드가 일시적으로 사용 중이면 제한된 횟수로 비동기 재시도합니다. 입력 변경·새 복사 요청·팝업 닫기를 구분하고, 앱 종료 뒤에도 복사 내용이 유지되도록 처리합니다.
- 팝업은 패킷을 전송하거나 TX 입력·모드를 변경하지 않습니다. 전송하려면 HEX 모드를 직접 선택하고 TX 입력란에 붙여넣은 뒤 전송 버튼을 누르세요.

## 선택한 응답의 값 해석

- CRC와 실제 길이가 정상인 FC03·04·17(HEX) 레지스터 읽기 응답을 UInt16, Int16, UInt32, Int32, Float32로 해석합니다.
- 시작 레지스터 위치, 배율과 바이트·워드 순서를 지정할 수 있습니다. 원본 패킷은 변경하지 않습니다.
- Float32 원본과 배율 적용 결과의 표시 정밀도를 보존합니다. 서로 인접한 값이 같게 보이거나 정확한 정수가 다른 값으로 반올림되는 문제를 수정했습니다.
- 요청·예외 응답·CRC 오류·불완전 프레임·역할이 모호한 패킷은 각각 다른 이유를 안내합니다. 작은 상세 패널의 입력 배치와 빈 결과 영역도 정리했습니다.

## 프로토콜 시간순 표시

- RX/TX 조립 완료 순서 대신 수신 관측 시각으로 목록을 정렬합니다. 뒤늦게 해석된 과거 프레임도 해당 위치에 표시하며, 선택·필터·일시정지 상태를 유지합니다.
- HEX 로그와 Protocol RX가 같은 수신 관측 시각을 사용합니다. 큐 지연이나 idle 대기로 생기던 시각 차이를 줄였습니다.

## 배포와 검증 범위

- GUI·CLI·설치 프로그램 버전은 1.6.5입니다. 설치형, 포터블, 플러그인, 기존 단독 스킬 ZIP과 SHA-256 체크섬을 제공합니다.
- 플러그인 버전 1.0.3과 기존 CLI/MCP 제어 API 1.x 호환을 유지합니다.
- Release 솔루션 빌드는 경고·오류 0개이며, 관련 Core 검사 82개와 WinUI 검사 216개를 통과했습니다. 장치 환경이 필요한 검사 1개는 제외했습니다. 배포 파일은 별도로 포함 파일과 체크섬을 검사합니다.
- 이번 릴리즈 작업에서는 GUI 실행·실장치 전송·장시간 안정성 검사를 수행하지 않았습니다.
- 업데이트 전 진행 중인 수집·시퀀스를 마치고 앱과 MCP를 종료하세요. 사용자 로그·프로필·제품 메모리와 AI 클라이언트 설정은 유지합니다.
