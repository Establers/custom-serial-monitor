# Serial Monitor v1.4.2

## 개선 사항

- 상단 오른쪽에서 COM 포트별 장치 이름을 지정할 수 있습니다. 이름은 창 제목에 표시되고 포트별로 기억하며, 여러 프로그램에서 동시에 저장해도 다른 포트의 이름을 덮어쓰지 않습니다.
- 상단 Logging 버튼을 우클릭하면 현재 또는 마지막 로그 파일이 있는 폴더를 엽니다. 아직 로그가 없으면 지정된 저장 폴더를 엽니다.
- 화면을 일시정지하면 재생 아이콘을 빨간색으로 표시하고, 재개하면 원래 색으로 돌아옵니다.
- Serial·Appearance·UI·Bridge·Test 선택칸의 폭과 라벨을 정렬했습니다. 긴 안내·상태 문구는 줄바꿈하고 좁은 패널에서는 가로 스크롤로 접근할 수 있습니다.
- 업데이트 확인은 About의 수동 확인 버튼을 눌렀을 때만 실행합니다.

## 안정성 수정

- 실행마다 WebView2 데이터와 진단 기록을 분리하여, 여러 창의 테마·로그 화면·오류 상태가 서로 영향을 주지 않도록 했습니다.
- COM 브리지에서 화면 렌더링 주기 때문에 수신 패킷 그룹이 쪼개지는 문제를 수정했습니다.
- 장치 이름의 제어 문자·깨진 유니코드·초과 길이와 손상된 저장 파일을 안전하게 처리합니다.
- 느린 CI 환경에서 재연결 테스트가 불필요한 비동기 전환과 짧은 제한 시간 때문에 실패하는 문제를 수정하고, 재시도·전송 순서 검증을 보강했습니다.

## 배포 및 검증

- Debug·Release 전체 솔루션 빌드와 자동 테스트 630개(Core 35개, WinUI 595개)가 두 구성에서 각각 통과했습니다.
- Windows 10/11 x64용 설치 EXE, 포터블 ZIP 및 SHA-256 체크섬을 제공합니다.
- Microsoft Edge WebView2 Runtime이 필요합니다.
- 설정 화면의 실제 배치와 설치 UI 수동 검증, 실제 장비 장시간 실행은 이번 검증에 포함하지 않았습니다.
