# Serial Monitor v1.3.8

## 시퀀스 JSON 공유와 AI 작성

- JSON 파일 하나에 시퀀스 하나를 저장하고, 여러 파일을 선택해 한 번에 불러올 수 있습니다.
- 선택한 시퀀스를 내보내면 작성 설명서 `_manual`이 같은 JSON에 포함됩니다.
- 필수 필드 누락, 미지원 필드, 중복 키, 잘못된 타입·범위, 이름 중복이 있으면 전체 불러오기를 취소합니다.
- 파일 읽기·검증·정규화는 백그라운드에서 처리합니다. 파일당 2 MiB, 한 번에 100개 파일·합계 10,000 Step·16 MiB로 제한합니다.
- 시퀀스 관리 메뉴에 추가·불러오기·내보내기·편집·삭제를 모았습니다. AI 작성 안내에서 요청문과 JSON 양식을 복사할 수 있습니다.

## 실행 상태와 조작성

- 재생·정지 아이콘과 한 줄 상태 표시로 실행 상태를 확인할 수 있습니다.
- TX 성공 수/전체 전송 수, 실패 시도 수, 마지막 TX 시각·경과 시간, 반복·Step 위치, Delay 잔여 시간 및 재연결 상태를 표시합니다.
- 상태는 초당 갱신되고 정지 후에도 마지막 실행 결과가 남습니다. 표시 문자열과 툴팁은 짧은 미리보기로 제한합니다.
- 선택한 시퀀스와 무관하게 Stop은 현재 실행 중인 시퀀스를 정지합니다. 개별 Step 편집·삭제는 각 행에 배치했습니다.

## 부하 완화

- 지연 0의 동기 송신·재시도 루프가 주기적으로 제어권을 반환하도록 보완했습니다. 개별 송신의 소요 시간 상한이나 전체 백그라운드 실행을 보장하는 변경은 아닙니다.
- TX 후 맨 아래로 스크롤하는 동작은 유지하면서, 진행 중 추가 스크롤 요청을 하나로 합칩니다.

## 검증과 배포

- Debug와 Release에서 각각 자동 테스트 512개(Core 35개, WinUI 477개)를 통과했습니다.

- Windows 10/11 x64용 설치 EXE, 포터블 ZIP 및 SHA-256 체크섬을 제공합니다.
- Microsoft Edge WebView2 Runtime이 필요합니다.
- TX OK는 앱의 송신 완료 기준이며, 장비의 수신·명령 처리를 확인하는 ACK 검증은 아닙니다.
- 실제 장비 장기간 실행, WebView 부하 하의 입력 지연 및 화면 수동 검증은 이번 검증에 포함되지 않았습니다.
