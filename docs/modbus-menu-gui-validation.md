# Modbus 메뉴와 명령 편집 흐름 확인

## 변경 범위

대상 설정 안에 통신 대상·값 표시·항목 정의·그룹 관리·프로필 저장을 모은다.
표 위에는 도구 줄 하나를 사용하고, 긴 통계·그룹 상태·오류의 전문은 통신 상세에서 확인한다.
오류가 있다는 사실은 도구 줄에 계속 표시한다.

명령 팝업에는 고정 실행 대상·값·확인 방식과 실행·정지를 함께 둔다.
HEX와 긴 설명은 필요할 때 펼치며, 편집기를 적용하면 실행 팝업으로 돌아온다.
편집·적용·프로필 저장은 명령을 송신하지 않는다.

명령 편집기의 중간 단계/명령 저장 버튼을 없애고, 유효한 초안은 목록 이동과 새로 추가할 때
편집기 내부 목록에 반영한다. 잘못된 초안은 전환을 막고 입력을 보존한다.
**모니터에 적용**은 현재 초안까지 세션에 반영하며, 취소는 편집 전 설정을 유지한다.
**프로필 저장**은 재시작 후 다시 사용할 설정을 파일에 보관한다.

## 확인 방법

다른 UI 작업 채팅은 도구 줄·좁은 창 배치를 맡고, 이 작업은 명령 편집 흐름과 통합 GUI 검증을 맡았다.
두 변경을 합친 소스로 다시 빌드한 앱에서 확인한다.
테스트용 대상·명령은 로컬 프로필 복사본을 사용하고 자동 재연결을 끈다.
이번 메뉴 확인에서는 포트를 연결하거나 실제 장치에 송신하지 않는다.
실물 UART의 순차 실행·상태 확인·실패·정지 검증은
[기존 기록](../firmware/nucleo-f103rb-serial-lab/MODBUS-COMMAND-GUI-VALIDATION.md)에 별도로 남아 있다.

## 검증 결과 (2026-11-14)

도구 줄 `5808199`와 편집 흐름 `44f543e`를 `939c7c7`로 합쳤다.
GUI에서 발견한 선택 표시 문제는 `4b19537`에서 고쳤다.
각 GUI 실행 전 해당 소스로 Debug x64 `UpdatePreviewBuild=true` 빌드를 새로 만들었다.

| --- | --- |
| 한국어·어두운 테마, 창 1186×793 / 934×793 / 721×793 | 도구 줄 한 행 유지. 기본 패널 높이에서도 주소 20·21의 데이터 두 행이 보인다. |
| 721px 창의 ⋯ | 직접 쓰기와 사용 안내 팝업이 실제로 열리고 화면 안에서 읽힌다. |
| 대상 설정 | ID·기능·주소·수량·표시와 항목 정의·감시 그룹·프로필 저장을 한 곳에서 찾는다. 긴 설명은 접혀 있다. |
| 명령 팝업 | 고정 ID·주소·값·확인 방식을 먼저 표시한다. HEX는 기본 접힘이며 펼치면 두 단계의 패킷을 확인한다. |
| 유효한 단계 편집 | 첫 값 6→8 입력 후 두 번째 단계로 이동하면 목록에 8이 반영된다. 중간 저장 버튼은 없다. |
| 잘못된 입력 | UInt16에 65536 입력 후 다른 단계/명령을 선택해도 초안과 편집 대상을 보존하고 오류를 표시한다. |
| 선택 표시 보완 | 최초 GUI에서는 거부된 선택의 강조만 다른 행에 남았다. 수정 빌드에서는 실제 편집 행/명령으로 강조도 복원된다. 유효한 10 입력 후에는 다음 단계로 정상 이동한다. |
| 적용·저장·취소 | 적용하면 실행 팝업에 값 8·9가 표시된다. 디스크는 6·7을 유지하다가 프로필 저장 한 번에 8·9가 된다. 다음 편집에서 10을 자동 반영한 뒤 취소하면 실행 정의는 8·9를 유지한다. |

선택 표시 복원은 다음 UI turn에 표시만 맞추며, 대기 작업은 한 건으로 제한한다.
대화상자가 닫히면 이전 콜백은 무효화한다. 통신·검증·초안 반영 로직을 UI 콜백에 넣지 않았다.

- 통합 Release 솔루션 빌드: 경고 0, 오류 0.
- 통합 전체 검사: Core 723개, WinUI 2,262개 통과. 장치 환경 조건부 검사 17개 제외.
- 선택 표시 수정 후 Release/Debug 빌드: 각각 경고 0, 오류 0. 관련 WinUI Modbus 487개 재검사 통과.
- 한/영 리소스 키 918개 일치, 중복 없음. 변경 diff·문서 링크 검사 통과.
- GUI 동안 연결하지 않았고 RX/TX는 0이었다. 이번에는 실제 실행/정지의 UART 시험을 반복하지 않았다.
- 검증 앱만 종료하고 시작 직전 프로필을 바이트 단위로 복원했다.
  SHA-256: `ABC2F014E5E47736B0BA785F5B1267EB7E04836B4FA695E280D704EBF0E5BE6C`.

로컬 상세 결과는 `artifacts/modbus-ux-gui-20261114`의 TRX와 테스트 프로필·빌드 지문에 남긴다.
